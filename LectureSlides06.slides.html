Reading 06 Q&A¶

Q: Could you review how np.meshgrid is interacting with arrays as inputs? I'm a little confused how it got the outputs that we saw in the question

A: meshgrid is a quick way to set up grids of x and y pairs that cover some region of 2d space. It takes two 1D arrays and repeats one of them as rows and the other is repeated as columns. For example, with x = [1,2,3] and y=[-2,-1,0,1,2] meshgrid will give two arrays, pairs of x and y values organized in a regular grid: x_new, y_new = np.meshgrid(x,y) gives...

1 2 3        -2 -2 -2
1 2 3        -1 -1 -1
1 2 3   and   0  0  0
1 2 3         1  1  1
1 2 3         2  2  2

You can then use these values to create a new array of the same shape, based on the values in those arrays

1 2 3    -2 -2 -2      f(1,-2) f(2,-2) f(3,-2)
1 2 3    -1 -1 -1      f(1,-1) f(2,-1) f(3,-1)
1 2 3  &  0  0  0  =>  f(1, 0) f(2, 0) f(3, 0)
1 2 3     1  1  1      f(1, 1) f(2, 1) f(3, 1)
1 2 3     2  2  2      f(1, 2) f(2, 2) f(3, 2)
In [ ]:
import numpy as np
x = np.array([1, 2, 3])
y = np.array([-2, -1, 0, 1, 2])
x2d, y2d = np.meshgrid(x, y)
print(x2d.shape, y2d.shape)     # both (5, 3): len(y) rows, len(x) columns
f = x2d * y2d                    # f(x, y) evaluated at every grid point, no loop
print(f)

meshgrid makes pictures: two sources of waves¶

Every grid point gets its distance to two sources; the whole wave pattern is one line of array maths.

In [ ]:
import numpy as np
import matplotlib.pyplot as plt      # plotting is Day 07: enjoy it today

x = np.linspace(-10, 10, 801)
X, Y = np.meshgrid(x, x)             # 801 x 801 grid, no loop
r1 = np.sqrt((X - 2)**2 + Y**2)      # distance to source 1 at (2, 0)
r2 = np.sqrt((X + 2)**2 + Y**2)      # distance to source 2 at (-2, 0)
wave = np.cos(2*np.pi*r1) + np.cos(2*np.pi*r2)   # wavelength 1

plt.imshow(wave, origin='lower', extent=(-10, 10, -10, 10), cmap='RdBu')
plt.show()

np.where() with three arguments¶

np.where(condition, x, y) returns an array (not a tuple), same shape as condition: x where it is True, y where it is False.

In [ ]:
arr = np.array([1, 2, 3, 4])
arr2 = np.where(arr<3, # if this condition
                -arr,  # then fill element with this
                arr)   # else fill element with this
arr2

Q. The error says "Use a.any() or a.all()". What are those?¶

  • m.all(): True only if every element of m is True
  • m.any(): True if at least one element is True
  • m.all without () is the method itself — Python treats it as true, so assert m.all can never fail
  • safe.all(axis=0) asks the question column by column (Worksheet 06 Task 3d)
In [ ]:
import numpy as np
b = np.array([1, 2, 3])
m = b == [1, 2, 9]
print(m)
print(m.any(), m.all())
print(bool(m.all))

safe = np.array([[True, False, True],
                 [True, True,  True]])
print(safe.all(axis=0))

New today: a slice of an array is a view¶

In [ ]:
L = [-2, -1, 0, 1, 2]
s = L[1:4]
s[0] = 99
print(L)
  • c = a[1:4] copies nothing — it is a window onto a. Writing through the window writes into a
  • A list slice L[1:4] is a new list: L stays [-2, -1, 0, 1, 2]

View or copy? The four cases to know¶

you write you get writes back into a?
b = a the same object (alias, Day 05) yes
c = a[1:4], a[:, 0], a.T, a.reshape(...) a view yes
d = a[a > 0], a[[1, 3]] a copy (mask / fancy indexing) no
e = a.copy(), a + 0, a * 1, np.sort(a) a new array no

If a value changes behind your back — suspect a view. Not sure? a.copy() and move on. (This WILL appear on Test 2.)
