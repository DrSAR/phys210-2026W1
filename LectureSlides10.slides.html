Reading recap: fitting with curve_fit¶

from scipy.optimize import curve_fit

def line(x, m, b):          # x first, then the fit parameters
    return m * x + b

popt, pcov = curve_fit(line, x_data, y_data, p0=[20, 2])
m, b = popt                       # best-fit values, in the order of the def
dm, db = np.sqrt(np.diag(pcov))   # uncertainties
print(f"m = {m:.1f} ± {dm:.1f}")
plt.plot(xf, line(xf, *popt))     # *popt unpacks to m, b
  • popt: the best-fit parameters. pcov: the covariance matrix
  • The diagonal of pcov holds the variances: take the square root to get the uncertainties

Error bars in the fit¶

popt, pcov = curve_fit(line, x_data, y_data, sigma=yerror, absolute_sigma=True)
  • sigma=yerror: each point counts with weight $1/\sigma^2$, so points with small error bars pull the fit harder
  • absolute_sigma=True: the error bars are absolute, in the units of $y$. Without it, curve_fit uses only their relative sizes and rescales the uncertainties
  • In this course: when you have error bars, use both

Residuals and starting values¶

  • Residual = data − model, at each data point. Good fit: residuals scatter at random around 0; a pattern (a U, a trend) means the model is missing something
  • curve_fit makes the sum of the squared residuals (SORS) as small as it can. With sigma, each residual is divided by its error bar first: that sum is $\chi^2$
  • No p0: curve_fit starts with 1 for every parameter
  • It walks downhill from p0 and stops at the first minimum it finds: maybe only a local minimum
  • So guess p0 from a plot of the data: amplitude, period, offset, decay length

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import curve_fit

np.random.seed(10)
x = np.linspace(0, 10, 30)
yerr = np.full(30, 2.0)
y = 0.5 * x**2 + np.random.normal(0, 2, 30)

def line(x, m, b):
    return m * x + b

def parabola(x, a, b, c):
    return a * x**2 + b * x + c

p_line, c_line = curve_fit(line, x, y, sigma=yerr, absolute_sigma=True)
p_par, c_par = curve_fit(parabola, x, y, sigma=yerr, absolute_sigma=True)

Slider demo: what the sliders and the button do¶

In [ ]:
def update(change=None):
    a, omega = a_slider.value, w_slider.value
    res = y_data - sin_model(t_data, a, omega)
    guess_line.set_ydata(sin_model(t_fine, a, omega))
    res_dots.set_ydata(res)
    fit_line.set_data([], [])
    readout.value = f'SORS = {np.sum(res**2):.1f}'
    fig.canvas.draw_idle()

def fit_from_here(b):
    p0 = [a_slider.value, w_slider.value]
    popt, pcov = curve_fit(sin_model, t_data, y_data, p0=p0)
    fit_line.set_data(t_fine, sin_model(t_fine, *popt))
    sors = np.sum((y_data - sin_model(t_data, *popt))**2)
    readout.value = f'fit: a = {popt[0]:.2f}, omega = {popt[1]:.2f}, SORS = {sors:.1f}'
    fig.canvas.draw_idle()

a_slider.observe(update, 'value')
w_slider.observe(update, 'value')
button.on_click(fit_from_here)
update()
widgets.VBox([widgets.HBox([a_slider, w_slider]), widgets.HBox([button, readout]), fig.canvas])

%matplotlib inline
plt.close('slider-fit')

def get_sors(a, omega):
    res = y_data - sin_model(t_data, a, omega)
    return np.sum(res**2)

a_vals = np.linspace(0.1, 3, 80)
w_vals = np.linspace(0.1, 2, 80)
A, W = np.meshgrid(a_vals, w_vals)

SORS = np.empty_like(A)
for i in range(A.shape[0]):
    for j in range(A.shape[1]):
        SORS[i, j] = get_sors(A[i, j], W[i, j])
