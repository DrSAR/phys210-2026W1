More on array indexing...

For the following 3D array a3, you would index a cell as a3[i, j, k].

  • The last index, $k$, selects the column,
  • The second-last index, $j$, selects the row,
  • The third-last (or first in this case) index, $i$, selects the plane/layer.

We could choose the middle row from each layer using either...

a3[:,1]
a3[:,1,:]

Reference vs new object creation¶

Objects like lists or arrays can have multiple names that reference the same object

  • a = [1, 2, 3], b = a: a and b are different names for the same object
  • If instead we’d said: b = a * 1 then b and a would a new object
  • After setting b = a, operations like: a[0] = 5 change both a and b since they both reference the same object

You will usually want to use b = a.copy() instead of a = b when making copies of mutable containiners such as lists or arrays
